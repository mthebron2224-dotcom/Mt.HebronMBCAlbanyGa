# Mount Hebron Missionary Baptist Church website

This is a static website: no WordPress, database, plugins, or server-side code.

## Files
- `index.html` — website
- `styles.css` — design and responsive layout
- `assets/` — cropped church images supplied for this site

## Free hosting
You can publish this site for $0/month using a static hosting service such as GitHub Pages or Cloudflare Pages. A custom domain is optional and normally has a yearly registration cost.

## Before publishing
1. The Cash App button is set to $hebronjoy. The Givelify button opens Givelify securely and tells visitors to search for Mt Hebron Baptist Church Inc in Albany, GA. If the church has a direct Givelify URL, replace that button URL with it.
2. Add the church phone/email if desired.
3. Review the event date and other announcements whenever they change.
4. Keep the social links pointed to accounts controlled by the church.

## Security
Because this is a static site, there is no public database, WordPress admin panel, or plugin system to attack. Use a strong, unique password and two-factor authentication on the hosting account and social accounts. Do not collect credit-card information directly on this website.
